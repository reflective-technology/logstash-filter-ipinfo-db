=== logstash-filter-ipinfo-db-zuin filter plugin

include::{include_path}/plugin_header.asciidoc[]

==== Description

The ipinfo filter adds information about the geographical location  and autonomous system number (ASN) of IP addresses,
based on data from the ipinfo.io free country and ASN database.

For example, if you have a field named `foo` which you want to lookup for location and ASN in ipinfo.io free database, and you want to store the
result of lookup in `bar`, do this:
[source,ruby]
    filter {
      ipinfo-db {
        source => "foo"
        target => "bar"
        token => "${IPINFO_TOKEN}"
      }
    }

[id="plugins-{type}s-{plugin}-database"]
===== `database`

  * Value type is <<string,string>>
  * Default value is `<path.data>/plugins/filters/ipinfo-db/country_asn.mmdb`

Path to the ipinfo `.mmdb` database file. If the file exists, the plugin uses it as is. If it does not exist,
the plugin downloads it to this path on startup using <<plugins-{type}s-{plugin}-token>>, creating parent
directories as needed. `path.data` is the Logstash data directory (for example `/var/lib/logstash` for
deb/rpm installs and `/usr/share/logstash/data` in Docker). Use an absolute path; a relative path is resolved
against the Logstash working directory.

[id="plugins-{type}s-{plugin}-database_age_warning_days"]
===== `database_age_warning_days`

  * Value type is <<number,number>>
  * Default value is `30`

The plugin does not update the database by itself. It logs a warning when the database was built more than this
many days ago, using the build time stored in the `.mmdb` file. The check runs at startup and then once a day.
To refresh the database, delete the file so it is downloaded again on the next start, or replace it with a newer
copy. Set to `0` to disable the warning.

[id="plugins-{type}s-{plugin}-source"]
===== `source` 

  * This is a required setting.
  * Value type is <<string,string>>
  * There is no default value for this setting.

The field containing the IP address or hostname to map via ipinfo-db plugin. The field to lookup in ipinfo database.

[id="plugins-{type}s-{plugin}-tag_on_failure"]
===== `tag_on_failure`

  * Value type is <<array,array>>
  * Default value is `["_ipinfo_db_lookup_failure"]`

Tags the event on failure to look up geo information in ipinfo.io free country and ASN database. This can be used in later analysis.

[id="plugins-{type}s-{plugin}-target"]
===== `target` 

  * Value type is <<string,string>>
  * There is no default value for this setting.
  * Default value is `ipinfo-db`

The field to write the lookup results into. 


[id="plugins-{type}s-{plugin}-token"]
===== `token`

  * Value type is <<password,password>>
  * There is no default value for this setting.

Your ipinfo.io access token, used to download the database when the file at
<<plugins-{type}s-{plugin}-database>> does not exist. If the file is missing and no token is set, the plugin fails to start.
To keep the token out of the pipeline config, use `${IPINFO_TOKEN}` with an environment variable or the Logstash keystore.
